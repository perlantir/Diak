  $ kill 56816

  $ hermes dashboard --no-open --port 9119 --host 127.0.0.1 &

  $ curl -sS http://127.0.0.1:9119/ | grep -oE '__HERMES_SESSION_TOKEN__="[^"]+"'

Conclusion: token is regenerated on every dashboard process start.
Source code confirms: hermes_cli/web_server.py line 74:

(generated at module-load time; not configurable via env or config.yaml)
