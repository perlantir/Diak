# Diak Chat Canvas Import Helper

This lightweight plugin stub exists to mirror the structure of the earlier package. Because this environment cannot generate a native `.fig` file directly, the recommended workflow is: 

1. Open Figma Desktop
2. Create a new file
3. Drag the SVG files from `artboards/svg/` into the canvas
4. Organize frames/pages as needed
5. Save or export the Figma file
